怎样比较才有参考价值

  1. 用不经过代理的网络，交替打开 GitHub Pages 和 Cloudflare Pages 的测试链接。
  2. 每家测 3 次，记录成功次数和时间；失败也要记录，不能只比较成功的那次。
  3. 再用手机流量重复一次，注明运营商。不要把不同网络的结果混在一起。

这里只测试轻量正文的可达性与加载表现，不是带宽测速，也不能代表全国或长期表现。重测会添加新查询参数，但 DNS、连接和平台缓存仍可能复用。

笔记阅读样例：先记录，再下结论

一篇有用的踩坑笔记，可以依次写下问题现象、运行环境、复现方法、排查过程和最终验证。保留失败尝试，往往比只写最后一条命令更有帮助。

网站也一样：能打开 是起点，持续访问是否稳定，才决定它适不适合作为个人主页。测试结束后，再制作正式的介绍、项目展示和文章归档。
